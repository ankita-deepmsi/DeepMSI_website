## Start locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verify before handover or release

```bash
npm run lint
npm run build
```

The project uses Next.js 16. Future contributors and coding agents must read the relevant installed guidance under `node_modules/next/dist/docs/` before changing framework-sensitive code.
